# SwingDesk

סורק סווינג למניות בארה"ב: סריקה, תוכנית מסחר, הזדמנויות אחרי ירידה וגאפים למטה, ומעקב מחירים עם התראות לטלפון.

## בענן (בלי מחשב)

המאגר הזה מריץ את SwingDesk ב-GitHub Actions:

| מתי | מה |
|---|---|
| כל ערב מסחר, 21:41 UTC (בחורף 23:41 שעון ישראל) | סריקה מלאה: תוכנית ליום הבא, הזדמנויות, בדיקה לאחור. סיכום לטלפון |
| כל רבע שעה, מהפרה-מרקט עד הסגירה | בדיקת מחירים: טריגר שנכנס, פתיחה מעל סף הביטול, הזדמנות שהופעלה או שברה תמיכה. התראה לטלפון |

התוצאות מגיעות לאפליקציה **ntfy** בטלפון, ולדשבורד בכתובת GitHub Pages של המאגר. הדשבורד לקריאה בלבד ומוצפן בסיסמה.

### מה מוגדר במאגר (Settings > Secrets and variables > Actions)

| סוד | חובה | מה זה |
|---|---|---|
| `DASH_PASSWORD` | כן | הסיסמה לדשבורד, 10 תווים לפחות. ממנה נגזר מפתח ההצפנה של כל הנתונים |
| `NTFY_TOPIC` | מומלץ | שם הערוץ ב-ntfy. נרשמים אליו באפליקציה |
| `SETTINGS_JSON` | לא | שינוי ספים, למשל `{"opp_min_drop": 20, "opp_min_stab": 4}` |
| `TG_TOKEN`, `TG_CHAT` | לא | טלגרם, אם רוצים גם אותו |

ובנוסף: **Settings > Pages > Source: GitHub Actions**.

### פרטיות

הקוד ציבורי. הנתונים לא: מצב הריצה (`state.enc` בענף `data`) והדשבורד (`data.bin`) מוצפנים ב-AES-256-GCM, במפתח שנגזר מהסיסמה (PBKDF2, ‏310,000 סבבים). בלי הסיסמה רואים רק קבצים מוצפנים. החלפת הסיסמה מתחילה מצב חדש.

### הרצה ידנית

Actions > SwingDesk > Run workflow. ‏`scan` מריץ סריקה מלאה, ו-`watch` בודק מחירים.

## במחשב

```
pip install -r requirements.txt
python swingdesk.py
```

הגרסה המקומית מלאה: סריקה לפי דרישה, לייב כל דקה, פוזיציות ויומן.

## מגבלות

- Yahoo Finance הוא מקור חינמי ולא רשמי, ומחירים בחלק מהמקרים בעיכוב של עד 15 דקות.
- GitHub מריץ משימות מתוזמנות לפי עומס. לפעמים ריצה מתאחרת בכמה דקות, ולעיתים רחוקות ריצה מדולגת.
- SwingDesk מיישם את הכללים שהוגדרו. זו לא המלצת השקעה.
